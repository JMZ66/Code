# 招投标文件审查助手 — 使用说明

## 1. 这是什么

这是一台电脑上就能用的 **只读核查** 工具，用来检查中国企业招投标相关的 Word（DOCX）、PDF、Excel（XLSX）材料：

- 是否符合指定官方 Word 模板的格式要求；
- 是否还有未填写内容、修订痕迹、批注；
- 正文、预算、技术附件、合同之间关键字段是否一致。

**它不会修改你的原始文件。** 所有结果写到单独的报告目录。

## 2. 安装（Windows 便携版）

1. 打开 GitHub Releases，下载最新的 `BidReviewAssistant-*-windows-x64.zip`。
2. 解压到任意目录（建议路径不要含特殊权限限制）。
3. 双击 `BidReviewAssistant.exe`。
4. 同目录下的 `使用说明.txt` 可快速查阅。

无需安装 Python，也无需联网。

## 3. 图形界面操作

1. 点击「添加 DOCX/PDF/XLSX」，可多选。
2. （推荐）点击「指定官方 Word 模板」，选择贵单位正式模板。
3. （可选）加载自定义格式 JSON。
4. 选择报告输出目录。
5. 点击「开始只读审查」。
6. 完成后打开报告目录中的：
   - `审查报告_*.xlsx` — 便于筛选与归档
   - `审查报告_*.html` — 浏览器阅读
   - `审查报告_*.md` — 文本/版本库友好
   - `审查报告_*.json` — 二次开发

## 4. 命令行（开发/批量）

```bat
BidReviewAssistant.exe 招标正文.docx 预算.xlsx 技术.pdf 合同.docx -t 官方模板.docx -o D:\reports
```

常用参数：

- `-t` 官方模板 DOCX
- `-p` 格式配置 JSON
- `-o` 报告目录
- `--role 文件名=正文` 手动指定角色（正文/预算/技术/合同/附件/模板）
- `--gui` 强制打开界面

## 5. 如何阅读报告

每条问题包含：

| 列 | 含义 |
|----|------|
| 严重程度 | 确定错误 / 疑似冲突 / 缺少依据 / 需要人工判断 |
| 原文位置 | 文件名、章节、段落/表格/单元格，PDF 尽量给页码 |
| 原文摘录 | 证据片段 |
| 判断依据 | 为何这样判 |
| 建议 | 人工处理建议（工具不自动改文件） |

**重要：** 同一事项在不同条件下的不同数值，可能标为「需要人工判断」，这是有意避免误报。

## 6. SHA-256 校验

报告中的「完整性校验」页记录了每个原文件核查前、后的 SHA-256。若不一致，工具会直接报错停止——说明有程序试图改写原文件，应立即停用并排查。

## 7. 常见问题

**Q: 会不会把 Word 格式“自动修好”？**  
A: 不会。本工具默认只读。

**Q: 能不能联网用大模型判断？**  
A: 当前版本刻意离线、不做云端调用。证据不足时转人工。

**Q: PDF 抽不出字？**  
A: 若是扫描件且无文字层，请先在本地做 OCR 后再导入；本工具不上传文件做云 OCR。

**Q: 误报怎么办？**  
A: 以「判断依据」和原文为准。条件条款、效力顺序差异导致的不同表述，优先人工确认。
