# 测试报告

测试时间以仓库 CI / 本地 pytest 为准。以下为复杂中文招标测试集（`testdata/complex_pack`）的验收摘要。

## 测试集植入问题

1. 正文工期 90 天 vs 交货章节 60 天  
2. 正文数量 2 台 vs 预算表 3 台  
3. 正文限价 120 万 vs 预算合计 160 万  
4. 技术附件检测限 0.05ppm vs 正文 0.1ppm  
5. 技术附件工期 3 个月（≈90 天）与正文一致  
6. 不可抗力延期、试运行调试期、质保响应等条件条款  
7. 未填占位与下划线  
8. 修订痕迹  
9. 文字正确但字体改为楷体  
10. 页边距被改文件  
11. 正文提及但未导入的附件材料  

## 结果（本地 pytest + 全量 CLI）

- `pytest tests`：**8 passed**
- 关键冲突（工期 90/60、数量 2/3、金额 120万/160万、字体、页边距、占位、修订、缺附件）均能检出
- 条件条款（不可抗力延期、试运行、质保响应）**未**被标成“确定错误”的无条件工期冲突
- 联合体“不接受/不允许”归一后 **无** 误报冲突
- 核查前后 SHA-256 一致

## 漏报 / 误报观察

| 类型 | 观察 |
|------|------|
| 漏报 | 扫描型 PDF、无书签复杂目录、合并单元格极不规则表仍可能漏抽 |
| 误报 | 极相近但语义不同的技术指标短句可能进入“疑似冲突”；需人工看上下文 |
| 未验证 | 每台 Win10/11 桌面实机点击、超大文件（>100MB）性能、加密文档 |

## 尚未验证的限制

- 未接入任何大模型；复杂法务歧义只能标“需要人工判断”
- 未支持 DOC（老格式）、WPS 专有对象、嵌入式 OLE 深度解析
- PDF 页码依赖文本层；版式还原不做
- GitHub `windows-latest` 打包成功 ≠ 桌面环境兼容性全部证明
