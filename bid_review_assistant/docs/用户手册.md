# 招投标文件审查助手 · 用户手册

## 这是什么

Windows 完全离线的中文招投标文件**只读**核查工具。用于检查：

- 对照官方 Word 模板的字体、字号、页边距、分节、页眉页脚、表格结构等
- 未填占位、缺失章节、重复段落、修订痕迹与批注
- 项目名称、工期、金额、数量单位、技术指标、资质、联合体等字段抽取
- 招标正文、预算表、技术附件、合同条款的跨文件一致性

**不会**自动改写 Word、统一格式、删除空白、修改编号或重建表格。  
**不会**上传企业文件或调用云端 API。  
**不会**编造招标要求、资质标准或法律条文。

## 安装与启动

### 便携版（推荐）

1. 从 GitHub Releases 下载 `BidReviewAssistant-windows-x64.zip`
2. 解压后双击 `BidReviewAssistant.exe`
3. 添加 DOCX/PDF/XLSX，可选指定官方模板，选择输出目录，点击「开始只读审查」

### 命令行（开发/脚本）

```bat
cd bid_review_assistant
python -m pip install -r requirements.txt
set PYTHONPATH=src
python -m bid_review 文件1.docx 文件2.pdf 预算.xlsx -t 官方模板.docx -o 审查输出
python -m bid_review --gui
```

## 报告说明

输出目录生成：

| 文件 | 内容 |
|------|------|
| `审查报告.xlsx` | 问题清单、字段、SHA-256 完整性 |
| `审查报告.html` | 便于浏览的彩色报告 |
| `审查报告.md` | Markdown |
| `审查报告.json` | 机器可读完整结果 |

每条问题包含：严重程度、原文摘录、文件名、章节、结构位置；PDF 尽量给出页码。

### 严重程度

| 级别 | 含义 |
|------|------|
| 确定错误 | 条件可比且证据充分的冲突或明确格式偏离 |
| 疑似冲突 | 有差异但效力/语境需再确认 |
| 缺少依据 | 引用了附件/字段但语料中找不到依据 |
| 需要人工判断 | 条件不同或无法仅凭数值判定 |

一致性引擎会比较条件签名（如“质保期/调试期/若…则…”）与文件效力顺序，**不会因为数值不同就一律判矛盾**。

## 完整性

审查开始前与结束后计算每个原始文件的 SHA-256。报告中「未改动=是」表示原文件字节未变化。

## 限制（请务必阅读）

- 复杂域、文本框、嵌入 OLE、扫描版 PDF（无文本层）支持有限
- 中文大写金额、手写批注图片无法可靠抽取
- 模板比对基于格式画像与标题集合，章节更名可能导致“缺少依据”类提示
- 本工具不能替代招标人/代理机构的合规审查责任
