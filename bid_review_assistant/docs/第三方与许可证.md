# 第三方组件与参考项目许可证核查

本工具为独立实现的只读审查程序。开发前已核查下列 GitHub 参考项目：

| 项目 | 许可证 | 本仓库态度 |
|------|--------|------------|
| AZ123IT/BidGuard-AI | MIT | 仅借鉴“证据优先”产品思路；其实现为 FastAPI/Next.js/pgvector 云端架构，**未复制代码** |
| heavenoracle/han-docx-lint | MIT | 借鉴只读 OOXML、占位检测、不上传的产品约束；**未 vendoring 其源码** |
| zwt0204/standardize-docx-format | **无开源许可（保留全部权利）** | **禁止复制** |
| dotnet/Open-XML-SDK | MIT | .NET 栈；本项目用 python-docx / lxml 读 OOXML，**未移植其代码** |
| ShayHill/docx2python | MIT | 可选依赖思路；当前默认直接用 python-docx，未强制捆绑 |
| tender-eval-ai/tender-evaluation-assistant | **AGPL-3.0** | **不复制代码**，避免 AGPL 传染 |

## 运行时依赖（PyPI）

| 包 | 典型许可证 | 用途 |
|----|------------|------|
| python-docx | MIT | 只读解析 DOCX |
| openpyxl | MIT | 只读解析 XLSX / 写出报告 |
| pypdf | BSD-3-Clause | 只读解析 PDF 文本与页码 |
| lxml | BSD | OOXML 修订/批注探测 |

打包工具 PyInstaller（GPL 例外许可，按其条款分发）仅用于构建 Windows 可执行目录，不进入源码逻辑。
