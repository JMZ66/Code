# 需求规格说明书 V0.1

## 1. 产品定位

面向中国企业分析化学检测实验室的 **Windows 离线危化品仓库管理软件**：电子台账、出入库、SDS、预警、盘点、操作追溯。

## 2. 非功能需求

| ID | 需求 |
|----|------|
| NF-01 | Windows 10/11 完全离线运行，无互联网/云 API/在线 AI 依赖 |
| NF-02 | 技术栈：Python 3.10+、PySide6、SQLite |
| NF-03 | 中文图形界面 |
| NF-04 | 可打包为单机 EXE（PyInstaller） |
| NF-05 | 支持 Excel 导入导出、PDF 报表、条码扫描枪（键盘楔入） |
| NF-06 | 库存修改必须形成独立交易记录；禁止删除历史出入库流水 |
| NF-07 | 需双人复核的业务必须由两个独立授权账户确认 |

## 3. 功能需求（V0.1）

### 3.1 化学品信息（FR-CHEM）

名称、CAS、浓度、规格、生产厂家、批次、有效期；关联危险类别（仅允许选用已审核分类数据）。

### 3.2 独立容器（FR-CTR）

每瓶试剂唯一编号与二维码；状态：在库/借出/处置/空瓶。

### 3.3 库存事务（FR-TX）

入库、领用、归还、调拨、处置；数量追踪；管制品出库需双人复核。

### 3.4 储存位置（FR-LOC）

仓库 → 分区 → 柜号 → 层位；储存条件字段（冷藏/阴凉/通风等，由人工维护）。

### 3.5 SDS（FR-SDS）

本地 PDF 存档路径、版本号、审核状态（草稿/已审核/作废）。

### 3.6 危险类别（FR-HZ）

分类数据需授权人员审核后方可用于标识；**系统不自动判定混储相容性**。

### 3.7 预警（FR-ALERT）

过期、低库存、超核定库存、缺失 SDS。

### 3.8 统计（FR-STAT）

库存汇总、出入库流水、月度消耗、盘点差异。

### 3.9 安全（FR-SEC）

角色权限、操作日志、数据备份与恢复。

## 4. 角色

| 角色 | 能力 |
|------|------|
| admin | 用户管理、备份恢复、全部业务、审核分类/SDS |
| warehouse | 出入库、盘点、容器与位置维护 |
| safety | 危险类别审核、SDS 审核、预警查看 |
| viewer | 只读查询与报表 |

## 5. 明确不做（V0.1）

- AI/规则引擎自动判定禁忌混储
- 在线监管平台对接
- 采购审批工作流、供应商门户
- 多组织租户与远程同步
