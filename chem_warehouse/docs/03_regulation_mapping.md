# 法规依据与功能对应清单（V0.2，2026-11 复核）

> **声明**：下列映射为公开法律/标准要点与软件功能的对照，**不构成法律意见**，亦**不能仅凭本软件主张已满足全部危化品安全法定义务**。分类、禁忌储存、核定储量、管制目录须由单位授权人员审核后录入；系统不做 AI 自动混储判定。

## 0. 规范时效（截至 2026-11）

| 规范 | 状态 |
|------|------|
| 《中华人民共和国危险化学品安全法》 | 2025-12-27 通过，**2026-05-01 起施行**（主席令第六十四号） |
| 《危险化学品安全管理条例》 | 仍为重要行政法规；与新法并行适用时以法律效力优先，具体衔接以主管部门解释为准 |
| GB 15603—2022《危险化学品仓库储存通则》 | 2023-07-01 起实施，继续适用 |

## 1. 《中华人民共和国危险化学品安全法》重点条款映射

适用条件提示：分析化学检测实验室通常属于法律所称“使用危险化学品的单位/检测机构”等；是否构成重大危险源、是否储存剧毒/易制爆，取决于实际品种与数量。

| 条款 | 要点 | 适用条件（摘要） | 系统功能对应 | V0.2 状态 |
|------|------|------------------|--------------|----------|
| 第2条 | 生产、储存、使用、经营、运输安全管理适用本法 | 单位从事危化品相关活动 | 产品定位：使用/储存台账辅助 | 范围声明 |
| 第5条 | 全员责任制、双重预防、信息化建设；主要负责人负责 | 危险化学品单位 | 角色权限、审计日志（辅助信息化） | 部分 |
| 第13条 | 重大危险源登记建档、备案储存数量/地点/管理人员 | 构成重大危险源的单元 | 位置/数量字段；**备案报表未完成** | 缺口 |
| 第31条 | 提供中文 SDS 与安全标签并相符 | 生产/进口企业义务；使用单位应获取并培训（见第51条） | SDS 本地存档、版本、审核、缺失预警、文件哈希 | 框架 |
| 第40条 | 剧毒/易制爆品种数量流向记录；丢失被盗报告 | 生产、储存（及第52条扩至使用单位）剧毒/易制爆 | 容器台账 + 不可删流水 + 双人；外部报警流程未做 | 部分 |
| 第41条 | 专用储存场所；剧毒及重大危险源**双人收发、双人保管**；收发记录保存≥3年 | 剧毒或重大危险源储存 | `controlled_flags` + 双独立账户；调整/盘点/冲正不可绕过；**未做满3年归档策略强制** | 部分（P0 已堵绕过） |
| 第42条 | 出入库核查登记；剧毒备案数量/地点/管理员 | 储存单位 | 出入库事务、位置；备案导出未完成 | 部分 |
| 第43条 | 专用场所标志与实体/技防；定期检测 | 储存单位 | 位置维护；技防设备管理未做 | 缺口 |
| 第45条 | 转产停业妥善处置并备案 | 生产储存单位（使用单位准用） | 处置事务类型 | 基础 |
| 第51条 | 向从业人员提供 SDS/标签并培训告知 | 使用单位 | SDS 查询；培训管理未做 | 部分 |
| 第52条 | 第37/38/40/45 条等适用于使用单位 | 使用危险化学品的单位 | 台账/双人/处置等按使用场景落地 | 部分 |
| 第38条 | 不得篡改、隐瞒、销毁监控相关数据信息 | 生产储存单位 | 流水不可删 + hash 链；**不能对抗 OS 管理员改库** | 部分+剩余风险 |
| 第102条等法律责任 | 未双人收发保管、未建出入库登记等可罚 | 违法情形 | 软件辅助留痕，不替代执法 | 声明 |

## 2. GB 15603—2022 要点

| 条款要点 | 系统功能对应 | 状态 |
|---------|-------------|------|
| 5.1 隔离/隔开/分离储存 | 位置层级 + 人工指定；无自动混储引擎 | 字段支持 |

| 5.10 剧毒/监控/易制毒/易制爆备案与双人 | 管制标识 + 双人复核 | 框架 |

## 3. 产品内强制安全约束（V0.2）

1. 危险类别/SDS/核定储量变更须授权角色审核标记。
2. 不得输出自动“可安全混储”结论。
3. 双人复核：`operator_id ≠ reviewer_id`，双方均具权限；管制品的领用/归还/调拨/处置/**调整**/冲正/盘点差异调整均适用。
4. `stock_transactions` 禁止删除；纠错用 `reversal`。
5. 演示模式与正式模式锁定隔离；正式模式禁止演示账户/固定弱密码/模拟危化品种子。
6. 备份含 DB+SDS+QR 与哈希校验；审计与库存事务同事务提交并具哈希链（仍无法对抗特权改库）。
