# 法规依据与功能对应清单（V0.1）

> 说明：下列条款为公开法规/标准要点摘录与功能映射，**不构成法律意见**。分类数据、禁忌储存、核定储量须由单位授权人员审核后录入；系统不做 AI 自动混储判定。

## 1. 《危险化学品安全管理条例》（国务院令，修订施行）

| 条款要点 | 系统功能对应 | V0.1 状态 |
|---------|-------------|----------|
| 第15条：提供 SDS 与安全标签信息相符 | SDS 本地存档、版本、审核状态；缺失 SDS 预警 | 已实现框架 |
| 第23条：剧毒/易制爆数量与流向记录、防丢失 | 容器级台账 + 不可删事务流水 + 操作审计 | 已实现框架 |
| 第24条：专用仓库存放；剧毒及重大危险源双人收发、双人保管 | `requires_dual_control` + 双账户复核 | 已实现业务校验 |
| 第25条：出入库核查登记；剧毒等备案信息 | 出入库事务、位置与管理员信息字段 | 部分（备案报表待后续） |
| 第26条：专用仓库标志与技防 | 位置/柜号维护；技防设备管理不在 V0.1 | 未完成 |
| 第27条：转产停业妥善处置 | 处置事务类型 | 基础出入库支持 |

> 注：用户所述《中华人民共和国危险化学品安全法》在公开检索中常见对应物为《危险化学品安全管理条例》及相关专项法规；本清单以条例及 GB 标准为主映射。

## 2. GB 15603—2022《危险化学品仓库储存通则》

| 条款要点 | 系统功能对应 | V0.1 状态 |
|---------|-------------|----------|
| 5.1 隔离/隔开/分离储存 | 位置层级 + 人工指定储存方式字段 | 字段支持；规则引擎不做 |
| 5.2 按特性与 SDS 选择仓储设施 | 储存条件字段；SDS 关联 | 已实现 |
| 5.3 严格控制品种与数量 | 核定储量 `approved_max_qty` + 超储预警 | 已实现 |
| 5.5 配存符合附录 A 与 SDS | **禁止 AI 自动混储判定**；仅保存已审核禁忌说明文本 | 人工维护占位 |
| 5.9 特定品种应分离储存 | 危险类别标识 + 人工审核分类 | 标识支持 |
| 5.10 剧毒/监控/易制毒/易制爆备案；双人收发保管 | 管制标识 + 双人复核 | 已实现框架 |

## 3. 管制化学品相关要求（易制毒、易制爆、剧毒、监控化学品等）

| 要求要点 | 系统功能对应 | V0.1 状态 |
|---------|-------------|----------|
| 台账清晰、流向可追溯 | 容器编号、事务流水、操作日志 | 已实现 |
| 双人收发/双人保管（及单位“双人双锁”制度） | 双独立账户确认；禁止共享账户 | 已实现校验 |
| 专用柜存放、不得与不相容品混放 | 位置分配由人工决定；系统可提示“需人工确认相容性”但不自动判定 | 人工确认勾选 |
| 丢失被盗报告义务 | 系统可记录异常处置原因 | 记录字段；外部报告流程未完成 |

## 4. 安全设计硬约束（产品内强制）

1. 危险类别、禁忌说明、核定储量变更须 `safety` 或 `admin` 审核标记。
2. 任何“是否可混储”的最终确认必须由授权人员人工完成；系统不得输出自动“可混储”结论。
3. 双人复核：`operator_id ≠ reviewer_id`，且双方均具备相应权限。
4. `stock_transactions` 禁止物理删除；纠错通过反向冲正事务。
5. 全量操作写入 `audit_logs`；支持数据库文件备份与恢复。
