# 未完成的安全合规事项（V0.1 之后）

下列事项**尚未完成或仅部分覆盖**，上线真实危化品作业前须由单位安全与合规责任人闭环。

## 法规与制度

1. 完整监管备案报表（储存数量/地点/管理员向应急管理、公安等部门备案格式）未实现。
2. GB 15603—2022 附录 A 禁忌配存规则库未内置；**刻意不提供 AI/自动混储结论**，目前仅有人工确认勾选与已审核说明文本表。
3. 重大危险源临界量核算、外部安全防护距离等不在本系统范围。
4. 演示数据中的管制标识（如丙酮）为功能演示，**不得当作正式管制目录**；正式目录须由授权人员导入并审核。
5. 丢失被盗的外部报警/报告流程、监控技防联动未实现。
6. “双人双锁”物理锁具与电子账户复核的现场作业规程需单位另行制定；系统仅强制双账户逻辑。

## 产品与运维

7. 密码策略、账户锁定、会话超时仍较基础（PBKDF2 本地哈希）。
8. 数据库文件级加密、介质防拷贝未做。
9. SDS 文件完整性校验（哈希）与版本强制关联出库未强制。
10. 电子签名/合格证影像归档未做。
11. Windows EXE 需在目标 Windows 环境打包与杀毒白名单验证（本云环境为 Linux，仅提供 spec/批处理）。
12. 尚未通过第三方安全评估或等保相关测评。

## 使用约束（必须告知用户）

- 本软件是台账与流程辅助工具，**不能替代**法定资质、行政许可、现场安全管理与专业判断。
- 危险分类、核定储量、禁忌储存、特殊化学品流程必须经授权人员审核后录入。
- 不得以共享账号完成双人复核。
