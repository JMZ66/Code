## 没有做成的东西

- **没有安装包。** Inno Setup 6.4 在这台运行器上没有 `ChineseSimplified.isl`，编译安装脚本失败。发布里只有便携版。
- 发布步骤第一次上传中文文件名的附件时返回 404，所以这次发布由该次构建的产物重新挂上，附件使用英文文件名。压缩包内部的手册仍是中文文件名。
- 没有在真实的 Windows 10 或 11 个人电脑上双击运行。
- 没有用 USB 扫码枪扫过标签。
- 没有在 Excel 或系统 PDF 阅读器里人工翻过报表。自动化测试用 openpyxl 读了单元格，用 pypdf 抽出了中文。
- 没有代码签名，因此不能声称通过了 SmartScreen，也没有任何安全认证或法定合规认证。

## 请您在自己的电脑上看的几件事

1. 解压便携版，双击 `ChemWarehouse.exe`，走完首次管理员创建。
2. 建一种试剂、一瓶，打开 `docs` 里的用户手册 PDF，看中文是否正常。
3. 若有 USB 扫码枪，在工作台输入框扫一次编号。
4. 若出现“Windows 已保护你的电脑”，是因为程序未签名。请让单位信息技术人员确认文件来源。这不是认证标志。
