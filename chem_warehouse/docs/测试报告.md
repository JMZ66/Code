## Windows 持续集成

工作流：`.github/workflows/chem-warehouse.yml`。

计划在 GitHub 托管的 `windows-latest` 上做三件事：

1. 跑和上面同一套 pytest。
2. 用 PyInstaller 打出便携目录，确认里面有 `qwindows.dll`，并用 `--gui-probe`（Qt offscreen）启动编出来的 EXE。
3. 对这个 EXE 加一条出站阻止规则，再跑 `--self-test`。结果写在该次运行生成的 `windows-verification.txt`。

**这些运行器是 Windows Server，不是 Windows 10 或 11 桌面。** 具体系统名称以那份 `windows-verification.txt` 里的 `runner_caption` 为准。在写出本段时，这一次 Windows 运行还没有结果，所以这里不填写通过或失败。发布说明和 Release 附件里的 `windows-verification.txt` 才是 Windows 上实际看到的记录。
