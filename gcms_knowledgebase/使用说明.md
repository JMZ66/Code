# 使用说明

GCMS 谱图知识库 1.0.0。界面是简体中文。程序离线运行，启动后不访问网络。

## 四个层次

屏幕上方的色条和报告里的工作表都按这四层分开：

1. **原始信号**：导入的色谱和单击得到的质谱。
2. **算法结果**：峰面积、峰高、解卷积得到的纯化谱。这里没有化合物名称。
3. **谱库候选（未确认）**：相似度排序。分数再高也不是鉴定。
4. **确认结论**：只有你做了“标准品确认”或“人工审核”才会出现，并写明操作者、时间和依据。

把谱图加入自建谱库，只是保存一条参考谱，不会把那个样品峰鉴定成该化合物。

## 安装和启动

发布包是 `GCMS_KnowledgeBase-win64.zip`。

1. 解压到任意文件夹。
2. 双击 `GCMS_KnowledgeBase.exe`，或双击 `启动GCMS知识库.bat`。
3. 不需要安装 Python，也不需要联网。

第一次打开会提示四层数据的区别。数据默认放在：

`%LOCALAPPDATA%\GCMS_KnowledgeBase`

里面有数据库 `gcms.sqlite3`、mzML 副本、色谱缓存和安全备份。原始 RAW / mzML 不会被移动或改写。

请先打开“设置 → 首选项”，填写操作者姓名。没有姓名不能保存确认或未知峰。

## 导入 mzML 和 RAW

“文件 → 导入 mzML”或“批量导入”可以选择多个 mzML。样品编号空着就用文件名。

RAW 不会由本程序直接解码。请先在设置里填写下面其中一个程序的完整路径：

- ThermoRawFileParser（推荐的调用方式是它自带的可执行文件。`-f=1` 表示普通 mzML。需要你本机能运行它；自包含包自带 .NET 运行时，框架依赖包则需要 .NET 8。）
- 或 ProteoWizard 的 `msconvert.exe`

这两个程序都不在本发布包里。许可结论见 `THIRD_PARTY_LICENSES.md`。

导入 RAW 时，程序只读打开原始文件，把 mzML 写到自己的 `converted` 目录，并在转换前后核对原始文件的 SHA-256。哈希变了会中止入库并提示。可以用“校验原始文件未被修改”再查一次。

批量导入时，每个文件的样品编号用文件名，仪器、方法和备注可以共用。

## 看色谱和质谱

选中左侧样品后，中间显示色谱。可以切换：

- TIC：每次 MS1 扫描的强度总和
- BPC：该扫描的最大强度
- EIC：指定 m/z，容差在设置里，窗口内的强度相加

在色谱上单击，下方显示最接近该保留时间的 MS1 谱。勾选“背景扣除”时，用峰两侧 TIC 较低的扫描按标称质量扣除。做不到时仍显示原始谱，并标明未扣背景。

随附公开示例的滤镜字符串是 `FTMS + p ESI Full ms [200.00-2000.00]`。那不是 GC-MS EI。合成文件会标明“合成数据”。

## 峰、积分和历史比较

“处理 → 峰检测与积分”对当前 TIC 做峰检测。平滑和找峰用 SciPy，面积是扣除两端线性基线后的梯形积分，单位是强度 × 分钟。

峰表只有保留时间、起止点、高度、面积、保留指数和算法名称，没有化合物列。

重新积分会把旧峰标成历史记录。已经写下的确认结论还在，但会注明关联的算法峰已有新版本。

“与历史样品比较”可叠加多条 TIC。归一化只用于看形状，定量仍看峰表里的面积。峰按保留时间容差对齐。

## 解卷积

“处理 → 解卷积”使用内置的离子色谱聚类和非负最小二乘。它按标称质量抽出离子色谱，把峰顶时间接近的离子收成一个组分，再用各组分的模型形状把重叠离子拆开。

这不是 MS-DIAL，也不是 AMDIS。结果放在“解卷积（算法结果）”，谱图是纯化谱，不是鉴定。

如果本机安装了 MS-DIAL 4 的控制台程序，可以在设置里填写 `MsdialConsoleApp.exe`，再用“运行外部 MS-DIAL（不入库）”。程序会按官方文档的 `gcms -i -o -m` 调用，输出留在数据目录的 `external` 文件夹。本版本不解析这些输出，避免把未核对的数字写进算法层。

AMDIS 的路径只能记在设置里，本版本不自动运行。

## 自建谱库

“谱库 → 导入 MSP”用 matchms 读取。名称、CAS、分子式、保留指数会进谱库。

“将当前谱图加入谱库”会再问一次名称。如果这是练习谱，请勾选合成。随程序附带 `示例_合成谱库.msp`，名称里写了“不能用于鉴定”，不要拿它出报告结论。

“对当前峰或组分检索”调用 matchms 的 `CosineGreedy`。默认权重是 m/z 的 1 次方、强度的 0.5 次方，m/z 容差 0.1。界面上的余弦范围是 0 到 1，不是 NIST 匹配因子。反向分数是先去掉查询谱里参考谱没有对应峰的离子，再用同一个函数计算。

查询谱和谱库条目都有保留指数时，差值超过设置里的容差（默认 20）的条目不会进入候选。缺一边的保留指数时不做这项过滤。

候选表的状态列固定是“谱库候选（未确认）”。

“导出 MSP”按 NIST 风格写出，供其他软件读取。

## 保留指数

“保留指数 → 烷烃校正并计算 RI”编辑正构烷烃的碳数和保留时间，也可以读入 CSV：

```text
carbon_number,rt_min,name
8,3.20,n-octane
9,4.10,n-nonane
10,5.00,n-decane
```

计算用程序升温的 van den Dool–Kratz：

RI = 100 × [n + (n2 − n) × (t − t_n) / (t2 − t_n)]

相邻烷烃时 n2 − n = 1，就是常用的那条式子。超出校正范围会外推，并在峰表里标出来。保留指数是计算值，不是鉴定。

校正必须和样品使用同一根柱、同一升温程序。本程序不把恒温 Kovats 指数当作默认方法。

## 确认、审核和未知峰

选中一个算法峰或解卷积组分后：

- “标准品确认”要求依据是标准品对照，证据里要写清保留时间、保留指数和谱图比较。只有分数不够。
- “人工审核”的依据是审核人判断，同样要写证据、姓名和时间。
- “登记未知峰”记入未知峰日志，带操作者和时间。

这三件事都写进数据库，不会因为相似度高而自动发生。

## 检索

“检索”可以按特征离子、名称、CAS、样品编号、保留时间窗口和保留指数窗口查找。结果按层分列：原始样品、算法峰、解卷积组分、谱库条目、谱库候选、确认结论、未知峰。名称只出现在谱库条目里时，不会同时变成确认结论。

## 报告

“导出 Excel 报告”生成多个工作表：封面、原始样品、算法峰、解卷积组分、谱库候选、确认结论、未知峰。封面写明相似度不是鉴定。xlsx 保存 Unicode 文本，字体样式写的是微软雅黑，但 xlsx 不能可靠地把字体嵌进文件。中文 Windows 一般能直接显示。

“导出 PDF 报告”嵌入文泉驿微米黑，换一台没有中文字体的电脑也能显示中文。条目很多时，PDF 列出前 300 条并写明总数。

## 备份和恢复

“文件 → 备份”把数据库和缓存打成 zip，里面有每个文件的 SHA-256。安全备份目录本身不会再打进新备份，避免越备越大。

“恢复”先校验清单和数据库完整性。校验失败就停止，当前数据不动。校验通过后，先把当前数据写成 `safety_backups/pre_restore_时间.zip`，然后才替换。不会静默覆盖。

请把备份 zip 拷到另一块磁盘。只放在同一目录里，磁盘坏了就一起丢。
