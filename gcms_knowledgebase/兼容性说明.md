# 兼容性说明

写这份说明时，没有在 Windows 10 或 Windows 11 桌面、也没有在任何气相色谱质谱仪旁边运行过程序。下面只记录实际读过的文件和实际没做的事。

## 已经读过的公开 mzML

文件：`src/gcms_kb/resources/testdata/public/small.pwiz.1.1.mzML`

来源：ProteoWizard 仓库 `example_data/small.pwiz.1.1.mzML`，Apache-2.0。原文件说明它来自名为 `small.RAW` 的 Thermo 文件。

本机用 pyteomics 读到的事实：

- MS1 扫描 14 个
- 保留时间约 0.0049 到 0.433 分钟
- 第一条扫描的滤镜字符串：`FTMS + p ESI Full ms [200.00-2000.00]`
- 这是电喷雾高分辨全扫描，不是 70 eV 电子轰击 GC-MS
- 程序自检导入的就是这个文件，日志里的 `synthetic=0` 表示它不是本程序生成的合成文件

因此，不能把这次读取写成“已验证 Xcalibur GC-MS RAW”或“已验证某型号气质联用仪”。

## 合成数据

峰面积、共流出解卷积、保留指数、谱库往返和界面冒烟用的是本程序写出的 mzML。文件里的软件标识是 `gcms_kb_synthetic`，滤镜字符串含有 `SYNTHETIC GC-EI`。这些谱图是为了让面积和解卷积有已知答案，不是仪器采集，不能当作标准谱。

## RAW 转换

代码可以调用本机的 ThermoRawFileParser 或 msconvert：

- ThermoRawFileParser：`-i` 输入、`-o` 输出目录、`-f=1` 普通 mzML、`-m=0`
- msconvert：`--mzML -o 输出目录`

输出目录被限制在本程序数据目录里。转换前后核对原始文件哈希。

这次没有拿到可以合法随测试分发、且确实是 GC-MS 的公开 Xcalibur RAW，也没有在 Windows 上跑通一次真实 RAW 转换。所以 RAW 兼容性是未验证。请在自己的 Win10/11 电脑上，用自己的文件离线试一次。

ThermoRawFileParser 2.x 的自包含包带有 .NET 运行时，不要求另外安装 .NET。框架依赖包需要 .NET 8。无论哪一种，里面的 Thermo RawFileReader 都不能放进本发布包，原因见许可审计。

## 解卷积和谱库

内置解卷积按标称质量处理，面向单位质量分辨率的 EI 数据做了合成共流出测试。它不是 MS-DIAL 或 AMDIS 的计算结果。高分辨数据会被收成标称质量，只能当粗工具。

相似度是 matchms `CosineGreedy`，不是 NIST 库的 Match Factor。不要把 0–1 的余弦乘 1000 以后当成 NIST 分数。本程序界面保留 0–1 的原值。

## 运行环境

目标是 Windows 10 / 11 64 位桌面，双击 exe 即可。GitHub 上的构建和冒烟使用 `windows-latest`，那是 Windows Server，不是 Windows 10/11。Linux 上只跑了自动化测试和自检，不能代替桌面验收。

程序运行时不下载词表、不检查更新、不上传数据。mzML 解析使用 pyteomics，并传入 psims 自带的 PSI-MS 词表，避免 pyteomics 5 去联网下载 obo。
