# 依赖与许可

本程序自有源码按 MIT 许可提供，见仓库 `lab_uncertainty_validation/LICENSE`。打包后的程序同时受依赖许可约束，不能把整个目录说成只受 MIT 约束。

| 组件 | 许可 | 作用 |
| --- | --- | --- |
| 本程序源码 | MIT | 计算、界面、测试 |
| NumPy、SciPy、pandas、pint | BSD-3-Clause | 数值、分布、表格、单位 |
| openpyxl | MIT | Excel |
| reportlab | BSD | PDF |
| pypdf | BSD-3-Clause | 提取 PDF 文本 |
| PySide6 / Qt | LGPL-3.0 或 GPL-2.0 或 GPL-3.0 | 界面。便携目录包含独立 Qt 库 |
| PyInstaller | GPL-2.0，带 Bootloader Exception | 仅打包 |
| 文泉驿微米黑 | Apache-2.0 | 中文和数字字形 |
| sandialabs/suncal | GPL-3.0 | 未复制，未打包 |
| lmfit | BSD | 未打包 |
| pandera | MIT | 未打包 |

LGPL-3.0、GPL-2.0、GPL-3.0 和 Apache-2.0 的文本在 `docs/licenses/`。字体说明在 `assets/fonts/NOTICE-WenQuanYi.txt`。

PySide6 以动态库形式放在便携目录中。替换兼容的 Qt / PySide6 库不应要求改本程序源码。PyInstaller 的 bootloader 例外允许把 bootloader 放进 exe；修改 PyInstaller 自身仍受 GPL 约束。本仓库没有修改 PyInstaller。

没有代码签名证书，因此没有对 exe 签名。
