# 已知限制和未验证事项

1. 本程序不声明 CNAS 认可，也不代替实验室授权程序。
2. 可执行文件没有数字签名。Windows 可能出现 SmartScreen 提示。
3. Windows 构建和自检跑在 GitHub `windows-latest`。该运行器是 Windows Server，不是 Windows 10 或 11 桌面。没有在实机上做鼠标图形交互验证。
4. 界面自检使用 Qt offscreen。它能创建窗口、计算、绘图、导出和写数据库，不能证明真实桌面的显示效果。
5. JJF 1059.1-2012 的官方全文没有取得，不能引用未核对页码。
6. JCGM 100:2008/Amd.1:2026 的修订全文没有取得。二阶项只是数值诊断，不加进 uc。
7. QUAM:2012 的编辑性勘误没有逐条并入。
8. MUPR 2026 的附录 A、第 8.3 节、式(7) 和含本底加标的式(10)–式(12) 没有实现。
9. 相关输入不计算有效自由度。非正态输入的相关不用高斯 copula，Monte Carlo 直接拒绝。
10. 不支持 JCGM 102 的多输出量，也不支持任意相关结构。
11. 反算不提供 Fieller 区间。斜率相对其标准不确定度过小时不给反算标准不确定度。
12. 失拟检验只用于普通最小二乘。二因素方差分析只接受每格重复次数相同且至少为 2 的平衡设计。
13. 负方差分量会保留原值，报告用的标准差把该分量截为 0。这是矩估计的处理，不是 REML。
14. k=2 不是无条件精确 95%。A 类 Monte Carlo 的标准差可以系统地不同于 GUM 的 u。
15. 自适应 Monte Carlo 有样本上限。未达到数值容差时，结果仍给出，但标明未满足停止条件。
16. 带零点偏移的单位（°C、°F）被拒绝。
17. 表达式中的纯数字是无量纲的，不会把 “/1000” 自动解释成单位换算。
18. 验收准则空白时状态是“未评价”。软件没有内置统一合格线。
19. 检出限计算本身永远标成未验证，除非只是记录用户提供的验证测定值；即使记录了，也不宣布合格。
20. 示例里的 ICP、迁移和标准溶液数据是模拟数据。磷酸盐例 2 是指南公开算例，不是本实验室数据。
21. 没有用企业原始数据验证。测试通过不能被说成科学正确性的证明。
22. 不是 LIMS，没有人工智能，也没有在线审批。
23. 便携版必须整夹复制。只复制 exe 会缺少 Qt 库、字体和文档。
