## 2026 年文献的核实结论

用户提到的 “Eurachem 2026 Evaluation of measurement uncertainty from in-house precision and recovery data” 与官网标题一致，年份是 2026，不是传闻。编辑为 R Bettencourt da Silva。它是第一版指南，不是法规。

没有实现、也不能假装实现的部分：

- 附录 A 的浓度依赖精密度模型
- 第 8.3 节用均方误差放大回收率不确定度
- 式(7) 不均匀样品
- 含本底加标的式(10)–式(12)，因为提取文本里的符号不够完整
- 式(19) 的绝对形式没有按编号实现；绝对模型在报告里单独写出

例 2 的独立复算：平均回收率 1.007900659，标准不确定度 0.037053561。指南在舍入后写作 1.008 和 0.03705。

## 程序里的主要公式

符号都在报告的计算过程里再次印出。

1. A 类实验标准差：`s = sqrt(Σ(x_i-x̄)^2 / (n-1))`。均值的标准不确定度是 `s/sqrt(n)`；单次结果的标准不确定度是 `s`，估计值必须另外填写。
2. 矩形分布：`u = a/√3`。三角分布：`u = a/√6`。`a` 是半宽。正态且用户给出半宽和 k 时，`u = a/k`。
3. 不相关：`uc^2(y) = Σ c_i^2 u^2(x_i)`。相关：`uc^2(y) = c^T Cov c`，`Cov_ij = r_ij u_i u_j`。
4. 不相关时 `veff = uc^4 / Σ (c_i u_i)^4 / v_i`。任一非零相关都不计算 veff。
5. 指定概率时，k 取正态或连续 t 分布的双侧分位数，不对 veff 向下取整。用户指定 k=2 时，只说明它在正态且自由度很大时约对应 95.45%，不是无条件的精确 95%。
6. Monte Carlo 估计是样本均值，标准差按 `1/(M-1)`。概率对称区间按 JCGM 101 第 7.7.2 节的顺序统计量。A 类抽样为 `x + scale·T_ν`，其分布标准差在 ν>2 时是 GUM 的 u 乘 `sqrt(ν/(ν-2))`。
7. 直线：加权正态方程。绝对权重 `w=1/σ^2` 时协方差不乘残差尺度；`1/x`、`1/x^2` 是相对权重，残差尺度另估，且 x=0 时拒绝。
8. 反算点估计 `(y-a)/b`。标准不确定度只用一阶传播，且在 `|b| < 3 u(b)` 时拒绝。不给出 Fieller 区间。
9. 单因素随机效应：`n0 = (N - Σ n_i^2/N)/(a-1)`，`s_between^2 = (MSB-MSW)/n0`。负值同时保留原值和截断为 0 的报告值。
10. 空白法：做空白校正时 `s′ = s0·sqrt(1/n+1/nb)`，否则 `s′ = s0/sqrt(n)`。`LOD = k_LOD·s′`，除非用户改选“空白均值 + k·s′”。k 没有默认值。
11. 校准法：`LOD = k·s_signal/|b|`，s 必须在信号域。
12. 单位面积迁移量：`q_A = (c_meas-c_blank)·D·V/A`。预期单位为 mg/dm²。再乘一次体积会使量纲不再是 mg/dm²，计算被拒绝。
13. 标准溶液：`c = m·P·v1/(V·v2)`。纯度 99.5 % 按 0.995 参加运算，原始 99.5 保留在输入里。
14. 相对自上而下、且用户声明回收率未包含在精密度中：不修正时 `uc = |x|·sqrt(RSD_I^2 + u(R)^2 + Σu_add^2)`；修正时 `y = x/R`，相对式中的回收率项改为 `u(R)/R`。
15. 平均回收率：`R̄ = Σ(x̄_i/c_i)/N`，`u(R̄) = sqrt(Σ u(R_i)^2)/N`。
