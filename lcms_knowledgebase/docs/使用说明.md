# 使用说明

LCMS_KnowledgeBase 是给分析实验室用的离线程序。双击 `LCMS_KnowledgeBase.exe` 即可，不需要安装 Python，运行时也不需要网络。启动时会有一个控制台窗口，用来显示错误信息，可以留着。

程序自己的数据库、转换结果和备份都在：

- Windows：`%LOCALAPPDATA%\LCMS_KnowledgeBase\`
- 测试或迁移时可以设置环境变量 `LCMS_KB_HOME` 指向别的目录

原始 mzML、mzXML 和厂商原始文件只读。程序不会把它们改掉或覆盖。

## 四层结果

界面顶部一直有这句话：原始信号、算法结果、谱库候选（未确认）、人工确认结论是分开的。

- 色谱和点开的质谱是原始信号，峰来自文件里真实存在的点。
- ppm、同位素棒图、空白比值、QC 漂移、谱图相似度是算法结果，不是鉴定。
- 检索命中写成“谱库候选（未确认）”。
- 只有在“结论”页填写依据并按“人工确认”之后，才变成“人工确认结论”。

程序不会生成一张质谱再把它显示成采集谱。测试用的合成文件如果被导入，表格的说明列会写“测试用合成数据”。

## 第一次打开

1. 打开“设置”，填写操作者姓名。以后的导入、确认和报告都记这个名字。
2. 若只分析 mzML / mzXML，到此即可。
3. 若要读厂商原始数据，先在本机安装转换程序，再把 exe 路径填到设置里。本程序不附带这些程序，也不会下载它们。

## 导入

“导入”页可以一次添加多个 mzML 或 mzXML。每一行可以改：

- 样品名
- 类型：未标记、样品、空白、QC、标准品
- 重复组
- 进样序号

点“开始导入”。程序计算 SHA-256，读完全部扫描后再算一次哈希。两次不一致就中止，不把这次导入写入数据库。

已入库表格里的“厂商推断”只是根据文件里的仪器和软件词条做的文字匹配，不是仪器鉴定。没有词条就显示“未推断”。

## 连接厂商转换程序

设置里填写：

- ProteoWizard 的 `msconvert.exe`
- 可选的 `ThermoRawFileParser.exe`

在“导入”页点“用外部程序转换厂商原始数据”，选择文件或目录（Agilent / Bruker 的 `.d` 是目录）。程序会问用哪一个转换器。`.raw` 可能是 Thermo，也可能是 Waters，程序不会因为扩展名就假定是 Thermo。

转换结果写到数据目录的 `converted` 子目录，不写到原始文件旁边。转换前后都会核对原始文件哈希。

msconvert 的默认命令是：

```text
msconvert.exe <原始文件> --mzML --outdir <本程序的输出目录>
```

默认不加 `peakPicking` 或其他滤镜。需要滤镜时只能由你在后续版本的额外参数里自己加；当前界面不提供隐藏滤镜。

ThermoRawFileParser 的默认命令是：

```text
ThermoRawFileParser.exe -i=<文件> -o=<输出目录> -f=2 -m=2 -p
```

`-f=2` 是 indexed mzML，`-m=2` 表示不另写元数据文件，`-p` 表示不用 Thermo 库做峰提取。峰提取会改变导出的谱图形态，所以默认关掉。原始 RAW 本身不会被改写。

其他厂商没有单独的解码器，而是交给装好了对应厂商库的 msconvert：

| 数据 | 通常的做法 |
| --- | --- |
| Agilent `.d` | msconvert，安装时带上 Agilent 库 |
| Waters `.raw` | msconvert，安装时带上 Waters 库 |
| SCIEX `.wiff` / `.wiff2` | msconvert，安装时带上 SCIEX 库 |
| Bruker `.d` / `.baf` / `.tdf` | msconvert，安装时带上 Bruker 库 |

这些厂商库有各自的再分发限制，所以不能打进本程序。MZmine 和 MS-DIAL 也一样：设置里填本机路径后可以启动它们，本程序不调用它们的算法，也不打包它们。

## 色谱图

选择一个或多个数据集，指定极性、质谱级别和扫描模式，再画 TIC、BPC 或 EIC。

- TIC 是该扫描里全部峰强度之和。
- BPC 是该扫描里的最高峰。
- EIC 只累加 m/z 窗口内真实存在的强度。窗口可以用 ppm 或 Da。
- 正离子和负离子不会加到一条曲线里。要看另一种极性，改下拉框再画一次。
- 默认扫描模式是“全扫描”，避免把 SIM 混进 MS1。需要看 SIM 时明确选择。
- 多条曲线是叠加比较，图例里带样品名。若文件被标成测试合成数据，图例会注明。

在图上单击（缩放模式未打开时）会跳到“质谱”页，显示该极性下离这个时间最近的 MS1。

## 质谱

显示刚才点中的那张谱：扫描号、极性、级别、扫描模式、保留时间、前体 m/z、碰撞能量和活化方式。扫描模式若是靠隔离窗口宽度推断的，标签带“推断”。峰表是这张谱里强度最高的峰，不是拟合出来的新峰。

## 精确质量和同位素

输入分子式和加合离子。支持的加合和源内丢失提示包括 `[M+H]+`、`[M+Na]+`、`[M+NH4]+`、`[M+K]+`、`[M-H]-`、`[M+Cl]-`、`[M+HCOO]-`、`[M+CH3COO]-`，以及失水、失氨等提示。质量用 pyteomics 的 NIST 数据计算。

可以再填一个观测 m/z，程序给出 Da 差和 ppm。ppm 的定义是（观测 − 理论）/ 理论 × 10^6。

若当前已经点开一张 MS1，程序会列出各加合离子理论 m/z 旁边最近的实测峰，并在图上用另一种颜色画出理论同位素分布。这些都标成辅助参考或理论值。小的 ppm 误差不是鉴定。

## MS/MS

列出该文件里真正采集到的 MS/MS：前体 m/z、碰撞能量、活化方式、极性和扫描模式（DDA、DIA、DIA/AIF、SRM 等，以文件里的词条为准）。

选两条谱可以互相比。只选一条时，用下拉框里的谱库条目做对照。默认拒绝不同极性或不同碰撞能量。只有勾选“允许比较不同极性或不同碰撞能量”才会继续，并且这个选择会记到算法结果里。

相似度是 matchms 的修正余弦（ModifiedCosineGreedy）。分数高只是算法结果。

把一条谱存入谱库时，标准品类型的样品会记成标准品条目，其他记成历史样品谱图。保存的是这张谱里的峰，并记下扫描号、哈希、极性和碰撞能量。

## 谱库

可以导入、导出 MSP 和 MGF。导出的是库里保存的峰和元数据。谱库条目不会因为导入就变成确认结论。

## 检索

可以按化合物名称、分子式、前体 m/z（ppm）、保留时间窗口、碎片 m/z 和极性检索。极性默认不混合。命中行的第一列是“谱库候选（未确认）”或“归档离子索引（算法结果，不是鉴定）”。

归档离子是导入时从每张谱留下的若干强峰，用来在大量历史文件里找特征离子。它不是完整的原始谱，原始峰仍以文件为准。

点“把选中行记为谱库候选”只会写入未确认候选。

## 空白、QC 和重复

先在导入时或本页把样品类型标成空白、QC 或普通样品。

空白比对：在选定极性下取全扫描 EIC，用样品最高点的保留时间去读空白上最近点的强度（不对不齐的时间做插值）。空白/样品 ≥ 阈值时标记“疑似空白污染”。这是算法结果。

重复或 QC：两条同极性全扫描 TIC 的时间点必须一致才计算皮尔逊相关，否则直接说明无法计算，而不是插值出一条新曲线。同时给出最高点的保留时间跨度和强度相对标准偏差，并按设置里的阈值标记是否超限。

## 结论

“结论”页列出全部记录。选中一条“谱库候选（未确认）”，写上依据，再点“人工确认”或“人工否定”。依据为空时不会保存。算法结果不能被确认成化合物。

## 报告

Excel 分表写出说明、数据集、算法结果、谱库候选、人工结论和溯源。PDF 使用随程序附带的文泉驿微米黑，以便显示中文。报告开头重复四层结果的界限。

## 备份和恢复

“立即备份”把数据库打成 zip，里面有清单和 SHA-256。不包含原始谱图。

“校验备份文件”只检查，不恢复。

恢复必须勾选确认。程序会先把当前库另存为 `pre-restore-*.zip`。这一步失败就中止，不替换当前库。清单哈希不对、zip 损坏或不是本程序的备份，都会拒绝。恢复不会悄悄覆盖而不留恢复前的备份。

## 大量历史数据

索引在 SQLite 里，数据集、扫描、前体 m/z、谱库名称和碎片 m/z 都有索引。自动化测试写入 3000 个数据集记录和 4000 条谱库记录后，按极性和前体窗口检索可以在 1 秒内返回。这测的是索引，不是 3000 个真实大文件同时打开。打开色谱时才会去读对应的原始文件。
