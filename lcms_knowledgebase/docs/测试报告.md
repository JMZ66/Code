## 持续集成

工作流：`.github/workflows/lcms-knowledgebase.yml`。

触发范围只包括 `lcms_knowledgebase/**` 和该工作流文件。运行器是 `windows-latest`，也就是 GitHub 托管的 Windows Server，不是 Windows 10/11 桌面。
