# 已知限制

这些是当前实现的边界，不是待补的空话。核对和改写都要带着这些限制读。

## 格式

- PDF 只有预留接口：记录 SHA-256，`status=reserved`，不抽文本。没有接入 pypdf。
- `.doc` 依赖本机 LibreOffice。本开发环境没有 `soffice`，只自动测试了“转换器缺失时原文件哈希不变、并明确报错”。没有用真实 `.doc` 做转换回归。转换会丢掉宏，修订和版式也可能变，转换结果不能当成与 `.doc` 字节级一致。
- `.xls` 不提供公式文本、批注、数据有效性。xlrd 2.0.2 在 `formatting_info=True` 下仍能读合并和隐藏；若以后版本去掉该参数，会退回并警告 `xls_formatting_unavailable`。
- 加密、权限密码、宏工程、RTF 不读。
- 页眉页脚里的自动编号没有按 `numbering.xml` 重算。正文编号会重算。

## 编号和样式

- 已实现的 `numFmt`：decimal、中文计数、中文大写、圆括号数字、圈号 1–20、罗马数字、字母、bullet、none。其余格式按十进制显示，并在 `warnings` 里记 `numfmt_fallback`。
- 省略 `w:start` 时按 ECMA-376 当作 0。Word 界面创建的列表通常会把 start 写成 1。
- `w:isLgl` 会把该级标签里的各级占位都显示成十进制，因此“第一章”下面可以得到 `1.1` 而不是 `一.1`。
- 表格样式的条件格式（首行、条带）没有套用。
- 主题色保留成 `theme:` 标记，不换成 RGB。东亚字体会按 `theme1.xml` 的 major/minor 解析。
- 编号级别自己的 `rPr`（只作用于编号符号的字体）没有单独套到正文 run 上。

## 内容对象

- 域（PAGE、REF、TOC）记录指令和缓存下来的显示文字，不更新域结果。
- 公式只读表达式和文件里的缓存值，不计算。缓存缺失就是 null。
- 图表、SmartArt、嵌入对象、VML、自定义 XML 只出现在 `features` 和改写警告里，不抽取内部文字。
- 文本框里的 `w:t` 会算进所在段落。SmartArt 的文字通常在 `diagrams` 部件，读不到。
- Excel 365 线程批注按部件关系做了尽力读取；老式批注走 openpyxl。两种都不是富文本往返。
- 内容控件和 `AlternateContent` 会进入 `Choice`（没有 Choice 才用 Fallback）。非常规嵌套仍可能漏。

## 核对

规则是确定性的，不是法律意见，也不是语义理解。

- 条款比对只认“第×条”和 `1.2` 这种编号，并且要落在同一个一级标题下。换一种说法不会自动对上。相同编号、不同标题不会硬比。超过 `clause_limit`（默认 50）会截断。
- 业绩门槛和评分只匹配固定句式（不少于 N 个、每 M 个得 X 分）。评分从 1 个起算、门槛是 3 个时会报“疑似冲突”，即使招标文件的本意是“先过资格再计分”。
- 技术参数只处理表头能对上的表，以及 `≥`、`≤`、不少于、不大于和数字区间。单位不同时报“需要人工判断”，不把 50 m 和 50 mm 判成同一个数。
- 人员资格看岗位名和证书名是否出现在人员表的对应列。不识别扫描件、照片和证书编号的真伪。
- 金额：同一段里的大写和阿拉伯数字；表内数量×单价；跨文件的固定标签（投标总价、合同金额等）。没有单位的相邻单元格按元估计，并降为疑似冲突。不把“万元”和“日历天”互相换算。
- 同名条款在两个文件里各写一遍、文字只差一个标点时，标点归一后可能不再报。只去空白和全角标点，不去同义词。

## 差异和改写

- `diff_documents` 按锚点对齐。中间插入一段落后，后面的锚点会整段变成新增或删除，不会按句子重新配对。这不是 Word 的修订红线。
- 改写只允许 `w:t`、`w:delText`，或一个单元格。不重组段落，不改样式，不重排节。
- 被改的那个部件会用 lxml 重新序列化，所以它的字节和原部件不同。结构比对忽略纯空白文本差异。其他部件按解压后的字节比较，必须一致，否则不把文件交给调用方。
- 共享字符串改成该格的 `inlineStr` 后，原共享项还在，只是少了一处引用。这是故意的：改共享项会波及其他格子。
- 不更新 `calcChain`、目录、交叉引用、脚注编号。打开 Word 或 Excel 后，域和公式仍可能变化。警告会列出这些对象，但警告不是“字节被改了”。
- 默认不覆盖原文件。

## 测试没覆盖的

- 真实招投标扫描件和甲方模板。样本是合成的。
- 真实 `.doc` 经 LibreOffice 往返。
- 极老的 Excel 5.0/95 特殊记录、宏工作簿 `.xlsm` 的 VBA 是否原样保留（部件哈希逻辑覆盖未改部件，但没有单独的宏样本）。
- Word 里的尾注、题注编号、多级 `lvlRestart` 的每一种组合。
- 性能：按招标文件常见体积来写，没有对几百兆工作簿做分页压测。MCP 的分页只保证不把整份结果一次返回给模型；进程内解析仍会读入工作簿。
