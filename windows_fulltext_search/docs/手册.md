# 本地全文搜索 使用说明

这是本机运行的全文检索程序。选定文件夹之后才会读取里面的文件。不会自动扫整块磁盘，不会上传内容，没有账号，也没有遥测。

## 运行

解压 `LocalSearch-1.0.0-windows-x64.zip`，双击 `LocalSearch.exe`。

包内有 `portable.marker` 时，索引、设置和历史都写在 exe 旁边的 `data/`。没有这个标记时，写在当前用户的应用数据目录。

程序没有数字签名。Windows 可能提示“未知发布者”。

便携包自带 `fonts/DroidSansFallbackFull.ttf`（Apache-2.0，版权属于 Google），用来显示中文，运行时不再下载字体。界面不是浏览器，不依赖 WebView2。

解析 Word、Excel、PDF、ODF、RTF 时会启动旁边的 `local-search-parse.exe`。请不要把它单独删掉。这个子进程有超时，Windows 上还会放进 Job Object 限制内存，并在任务结束时结束进程。这不是完整沙箱：没有 AppContainer，文档内容只当作数据，不会执行宏、脚本或公式。

## 建索引

左侧“添加文件夹”。不要选磁盘根目录或 `C:\Windows`。程序会跳过 `~$` 开头的 Office 临时文件，不跟随目录符号链接和联接点。

云占位文件（带离线、RECALL_ON_OPEN、RECALL_ON_DATA_ACCESS 属性）只跳过正文，不会为了索引去下载。本程序没有连接 OneDrive 账号。

第一次会把支持的文件抽出文本并写入索引。之后按修改时间和大小跳过没变的文件；内容变了会删掉旧文本再写入新的。文件被删或改名后，旧路径不再命中，也不会留下重复记录。如果整个根目录暂时打不开（例如移动磁盘拔掉），已有索引会保留，不会把里面的文件全部当成删除。

可以暂停、继续。关闭程序再打开，索引、文件夹列表和搜索历史还在。

“移除”只从列表和索引里去掉该目录的记录，不删除源文件。删除索引目录也不会删除源文件。

## 搜索

顶部是搜索框。默认是**子串**：整段输入按连续原文匹配，不会把 `AND` 当成运算符。

| 方式 | 含义 |
| --- | --- |
| 子串 | 连续字符，包括中文。`质量检测` 能命中 `包装材料质量检测报告`，`量检` 也能 |
| 短语 | 同样要求连续出现，空白也要一致。不是几个词分别存在 |
| 单词 | 按 Unicode 字母数字切分后的完整词。`quality` 不匹配 `qualitydetection` |
| 布尔 | 只在这个方式里识别大写 `AND`、`OR`、`NOT`。引号是短语，并排的词是 AND，不是短语。`-词` 表示排除 |
| 正则 | Rust 正则。能抽出必须出现的字面量时用索引预筛，然后再对已保存的原文核对。抽不出字面量时会逐份核对已保存文本，界面会说明它不能保证被索引加速 |

大小写：不勾选“区分大小写”时按 Unicode 小写比较，高亮位置仍对在原文上。勾选后 `QUALITY` 不会命中只有 `quality` 的文件。索引里保留原文，不是只存小写。

范围：正文、文件名，或混合（同一条查询在文件名或正文里成立即可）。

还可以按扩展名、路径包含、在设置里限制大小。排序有相关度、修改时间、文件名。结果分页，不会把全部命中堆成一长串控件。

预览是抽出的文本和命中上下文，不是 Word / Excel / PDF 的原生版式，也不执行 HTML 脚本。双击用系统方式打开原文件。右键可以打开所在文件夹、复制路径、复制匹配文本。

`Esc` 会作废当前这一代搜索，旧结果不会盖住新的查询。

## 索引里有什么

索引在本机，包含路径、文件名和抽出的正文。它不是加密的。请不要把索引目录同步到不受信任的位置。

## 支持的类型

见 `测试矩阵.md`。不支持 WPS 专用格式（`.wps`、`.et`、`.dps`）。扫描版 PDF 没有文本层时会说明，不会假装做了 OCR。
