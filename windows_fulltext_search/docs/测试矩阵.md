# 测试矩阵

2026-11-08 在 Linux 上用 `cargo test` 和 `LocalSearch --self-test-report` 跑过。Windows 打包自检由 CI 在 `windows-latest`（Windows Server，不是 Windows 11 桌面）上执行。

“只改扩展名”不算通过。下表里的 OOXML、ODF、RTF、HTML、PDF 都是按格式写出来的文件。

| 格式 | 状态 | 证据 |
| --- | --- | --- |
| txt / md | 通过 | 子串、短语、大小写、单词、布尔 AND/OR/NOT、分页 |
| csv | 通过 | 生成的表格能被索引；单元格按行号列出 |
| json / xml | 通过 | 正文里的中文能命中 |
| html | 通过 | 正文命中；`<script>` 里的 `SECRETTOKEN` 不进入文本 |
| rtf | 通过 | `\u` Unicode 中文被抽出并命中 |
| docx | 通过 | 正文、表格、页眉、页脚都有对应片段 |
| docm | 通过解析 | 与 docx 同一 OOXML 包，宏不执行。自检能索引生成的 docm |
| xlsx / xlsm | 通过 | `C3` 的缓存值 43 能定位到单元格；`D4` 只有公式、没有 `<v>`，搜索 `141` 不命中 |
| ods | 通过解析 | 生成的 ods 含缓存值 43 和无缓存公式。公式不会被执行 |
| pptx / odp | 通过解析 | 幻灯片文本按幻灯片编号写入 |
| pdf | 部分 | 两页 Helvetica 英文能定位到第 2 页；空页记为无文本、不做 OCR。中文 PDF 文本层未用样本验证 |
| odt | 通过 | 正文、表格、页眉、页脚 |
| doc / xls / ppt | 代码有读取路径，未用真实二进制样本验证 | `office_oxide` 0.1.16 能读这些格式，本仓库没有 LibreOffice/Excel 生成的有效中文二进制夹具 |
| xlsb | 未验证 | `office_oxide` 该提交含 xlsb 读取代码，但没有真实 xlsb 文件，不能把 OOXML 测试说成 xlsb 已通过 |
| wps / et / dps | 不支持 | 扩展名不在列表里 |

## 检索

| 用例 | 结果 |
| --- | --- |
| `质量检测` 命中 `包装材料质量检测报告` | 通过 |
| `量检` 命中同一句 | 通过 |
| `质量，检测` 命中带逗号的文件，不把 `质量检测` 当成同一处 | 通过 |
| 短语不是 AND | 通过 |
| `苹果 AND 香蕉` / `苹果 NOT 香蕉` | 通过。NOT 在全部候选上核对，不是先截断再排除 |
| 大小写：`QUALITY` 不命中只有 `quality` 的文件 | 通过 |
| 单词：`quality` 不把 `qualitydetection` 当成同一个词 | 通过 |
| 预筛结果与原文子串扫描一致（30 个合成文件、多组查询） | 通过 |
| 分页：20 条按文件名排序，第 2 页是 `n20.txt` 到 `n29.txt` | 通过 |
| 正则 `质.检` 用必须出现的字面量 `质` 预筛；`\d+` 不能预筛 | 通过 |
| `İ` 小写展开成 `i` + 组合附标时，高亮仍覆盖原来的一个字符 | 通过 |

## 索引维护

自检在同一进程里做了：改文件后旧句消失、新句命中；删除文件后不再命中；改名后只有新路径；重启后还能搜到；未改动文件的 SHA-256 不变。

云占位的判断是纯函数测试（OFFLINE、RECALL_ON_OPEN、RECALL_ON_DATA_ACCESS 会跳过）。没有连接真实 OneDrive。

## 性能

10 万份合成 txt 的实测写在 `性能报告.md`。那不是 10 万份 Office，磁盘也不是已确认的 SSD。
